01 / The work

Know what you are evaluating.

SettleLift is currently a software development preview. This website explains its workflows so a debt settlement team can evaluate the intended product without mistaking planned connections for an active service.

02 / The process

How the work connects.

  1. Can I enter real client records? No. The current browser workspace is for synthetic data. Real records require certified authentication, storage, permissions and connected operational services.
  2. Is there a Spanish interface? Yes, the preview and website offer English/Spanish. Authored case notes, client names and legal documents retain their original content unless deliberately translated and reviewed.
  3. Can the software guarantee creditor acceptance or a particular saving? No. A workflow can track proposals and evidence, but the website makes no guaranteed outcome claim.
03 / Context & decisions

The details that matter.

Pricing, paid onboarding and a public launch date have not been published. No card collection, consumer enrollment, banking connection or automatic subscription is activated here. Multi-office tenancy, client portals and creditor exchanges have prepared access designs that still need real-service verification. The feature pages provide the current scope for each area; the implementation page describes the remaining launch work.

05 / Common question

How do I evaluate the product without confusing it with a live service?

Use the feature pages and roadmap, review the prototype only with synthetic records, and check the connection status before assuming any external action is available.
